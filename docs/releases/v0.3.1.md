rfig v0.3.1 adds nested help-based completion across zsh, Bash and Fish, and improves upgrades and terminal output handling.

- `rfig analyze <command>` walks declared subcommands breadth first to leaf commands, with per-path caches, no fixed depth limit, serial sandboxed probes, and repeated-parent detection.
- Subcommand groups can use cached children when existing definitions return only filesystem fallback. Empty results can use the cache; native dynamic leaf arguments remain available.
- Completion diagnostics no longer corrupt the editing line or become candidate rows.
- Homebrew setup links shell adapters to the stable `opt` path, so a package upgrade updates scripts for new shell sessions. Run the new setup once per configured shell to migrate older copied adapters.
- Improved help parsing, Bash generated-definition loading, and test process cleanup.

## Upgrade

```sh
brew update
brew upgrade tamia6/tap/rfig
# Once when migrating a pre-v0.3.1 copied adapter:
"$(brew --prefix rfig)/bin/rfig" setup --shell zsh
# Use bash or fish for other configured shells, then open a new session.
rfig analyze cf
```

Keep a single installation method. If an old `~/.local/bin/rfig` shadows Homebrew, back it up and remove that duplicate executable before using the Homebrew installation. History and usage data are retained.
