HOW IT WORKS

从安装到顺手，
只差一次设置。

rfig 扫描本机命令和补全定义，后台逐个分析尚缺少规则的工具。无需预装一整套固定的命令库。

01安装 rfig

选择 Homebrew、预编译包或源码安装。

02运行 setup

扫描命令并写入 zsh 集成，后台继续补齐候选。

03打开新终端

输入命令，候选自然出现在光标下方。

GET STARTED

现在，打开你的终端。

当前版本支持 macOS zsh。选择适合你的安装方式；其他 Shell 的交互集成仍在计划中。

在终端运行
brew install tamia6/tap/rfig
rfig setup

安装后打开新的 zsh 终端即可使用。
